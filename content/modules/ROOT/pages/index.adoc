== How this Roadshow works

* *This page is home* — Credentials and console links live here. Use the home button anytime you get lost.
* *Navigate with the table of contents* — Modules are in the left table of contents, or use *Next* at the bottom of each page.
* *Use consoles in Showroom, or open them in a new tab* — Keep this guide open. Prefer the console tabs on the right of the lab UI. To open a link in a new browser tab: on a Mac, *<cmd> click*; on Windows/Linux, *<ctrl> click* or right-click → "Open in new tab."
* *Use the terminal tab for command line work* — Run `oc`, `roxctl`, and `podman` on the RHEL bastion.
* *Cluster setup and services are managed by GitOps* — RHACS, Quay, GitOps, Compliance Operator, and the vulnerable demo apps are already synced by Argo CD. Deleting resources by accident is no problem, as they will be recreated by GitOps.
* *You can go through the catalog in order, or jump in. The modules are designed to not be influenced by each other.* — 101 → 201 → 301, then the product deep-dives (RHACS, Virtualization, Lightwell TSSC).

== Environment setup

The following script asks you to choose the Lightspeed LLM provider and paste that provider's API key, reads Quay and RHACS credentials into your shell, and installs the TSSC CLIs (`cosign`, `oc-mirror`, `ec`).

OpenShift Lightspeed uses an LLM API key. The choice is cluster-wide, meaning everyone on this cluster shares the provider you save. Press Enter at the token prompt to leave Lightspeed unchanged.

Choose OpenAI, Azure AI, Anthropic, Google Gemini, or Other, then paste that provider's API key. The script selects the model and the endpoint. Press Enter to accept a shown default, or type a value to replace it. Other asks for the endpoint and model name.

When a saved API key still authenticates, the script skips the provider prompt. To replace that key, export `LIGHTSPEED_PROVIDER` and `LIGHTSPEED_API_TOKEN` before running the script. When the saved key is missing or the provider rejects it, the script asks again and offers *Keep the current provider*. That choice stores a new key and leaves the provider and model as they are.

[source,bash,subs="+macros,+attributes",role=execute]
----
git clone https://github.com/rhpds/ocp5-rhacs-showroom.git
cd ocp5-rhacs-showroom
bash setup/lab-environment.sh
source ~/.bashrc
----
