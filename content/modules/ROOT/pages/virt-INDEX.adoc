== Overview

These labs walk the link:https://access.redhat.com/sites/default/files/attachments/rh-openshift-virtualization-hardening-guide-detail-202512-en.pdf[Red Hat OpenShift Virtualization hardening guide^] on a cluster that already has OpenShift Virtualization installed. You audit every control, compare it to the secure default, and record what you would change to reach a hardened baseline.

NOTE: The guide uses CIS-style Level 1 / Level 2 labels and is not an official CIS benchmark yet. 

Lab details and prerequisites:

* OpenShift cluster with OpenShift Virtualization (CNV) in `openshift-cnv`
* Cluster-admin (or equivalent) for HyperConverged, RBAC `who-can`, and node debug 
* A running VM to inspect: this environment uses `rhel9-vm` in project `rhacs-virt`
* Credentials and console links are on the xref:index.adoc[home page]

Modules are sequential are recommended to be completed in order.
